Hi, I'm Marco. I'm a frontend architect from Stuttgart and spend most of my time on design systems and Web Components.
 
Things I build in my spare time:
 
- [epaper-components](https://github.com/marcomattes/epaper-components): UI components for e-paper displays that work without a framework. Docs are at [epaper-components.dev](https://epaper-components.dev).
- [reterminal-departure-board](https://github.com/marcomattes/reterminal-departure-board): ESPHome firmware that turns a reTerminal into a departure board for Stuttgart public transit. No cloud involved.
- [Clessira](https://github.com/Clessira): a macOS time tracker that keeps everything on your machine. There is a [VS Code extension](https://github.com/Clessira/vscode) and an [SDK](https://github.com/Clessira/sdk) for its local API.
I also contribute to [siemens/ix](https://github.com/siemens/ix/pulls?q=is%3Apr+author%3Amarcomattes) and [stencil/core](https://github.com/stenciljs/core/pulls?q=is%3Apr+author%3Amarcomattes)..
